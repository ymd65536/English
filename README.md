## 概要

Engineerが英語修行

## 練習法の名前

やっているといろいろ出てくるのでメモします。

### ディクテーション

Dictation：聞いて書き取る。目的としては聞き取れない単語は書き取れないので認識ができていないのでまずは認識できるようにする。
※音を聞いても文字起こしができないので結果として起こされた文章を読んだときに「あー！知ってたのに認識できなかった！」ということになる。

### サイトトランスレーション

英文を意味のかたまり（チャンク）ごとにスラッシュ（／）で区切り、英語の語順のまま前から順に日本語に訳していく練習法です。
※英語を読んで順番に読んで翻訳します。

スラスラやることがコツです。実際に技術ドキュメントでもやっていることをやっていくのが良いです。

ex) I am Yamada.
私/です/やまだ という順番で訳して理解する。語順を入れ替えない理由としては実際の英語リスニングでは単語が左から右に向かって聞こえてくるので
並び替えながら理解するのは非効率でそもそも頭がついていかないのが普通です。

### オーバーラッピング

Overlapping：発音に被せて自分も発音する。文章を読まず、音声を聞いてやるのが基本です。

### シャドーイング

Shadowing：1語か2語遅れて自分も発音する練習法です。文章を読まず、音声を聞いてやるのが基本です。

### チャンクリーディング

Chunk Reading:長い文章を切って読む。英語のまま理解する。
※昔やった木を見て林を見て森を見るという長文の英語読解術を思い出すと良さそう
