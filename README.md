# 英語やるぞ

## 概要

Engineerが英語修行

## 練習法の名前

やっているといろいろ出てくるのでメモします。

### ディクテーション

読んで書き取る。目的としては聞き取れない単語は書き取れないので認識ができていない。
つまりは音を聞いても文字起こしができないので結果として起こされた文章を読んだときに「あー！知ってたのに認識できなかった！」ということになる。

### サイトトランスレーション

読んで翻訳（スラスラやる）
実際に技術ドキュメントでもやっているが、普通にやれているので得意なのかもしれない。もうちょい磨く

### オーバーラッピング

発音に被せて自分も発音する。

### シャドーイング

1語か2語遅れて自分も発音する。

### チャンクリーディング

長い文章を切って読む。
※昔やった木を見て林を見て森を見るという長文の英語読解術を思い出すと良さそう
