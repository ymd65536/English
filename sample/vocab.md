# vocab

## 設定ファイルに使われる表現

`omitted`は`指定されない`と表現できます。

```text
If omitted, the default value is 30.
訳：指定されない場合、デフォルトの値は30です。
```

```text
If omitted, all repositories are included.
訳：指定されない場合、すべてのリポジトリが含まれます。
```

```text
If omitted, the current directory is used.
訳：指定されない場合、カレントディレクトリが使われます。
```

`If omitted`は`If it is omitted`となるために受け身の表現となります。

## whetherを使った文章

```text
This setting controls whether logging is enabled.
訳：この設定はログを有効にするかどうかを制御します。
```
